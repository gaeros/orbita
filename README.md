# Orbita

Orbita è una PWA indipendente e senza scopo di lucro per seguire i lanci spaziali in italiano e in inglese. Il calendario usa i dati di Launch Library 2, mostra gli orari di Roma e permette di filtrare per operatore e vettore.

## Avvio locale

Con Node.js 22.16 o successivo e Python 3 installati, esegui dalla cartella del progetto:

```sh
npm ci
npm run build
npm start
```

Apri [Orbita in locale](http://127.0.0.1:4174/). La build genera il sito statico nella cartella `dist/`.
